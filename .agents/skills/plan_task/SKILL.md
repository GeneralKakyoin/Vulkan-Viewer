Skill: plan-task

Use this skill when a meaningful task needs a written plan.

Steps:
1. Read `AGENTS.md`
2. Read required continuity docs based on task size
3. Read relevant code and existing artifacts
4. Draft a plan in `docs/plans/`
5. Ensure the plan includes objective, scope, touched files, boundary check, steps, validation, risks, and completion criteria
check docs/FIELD_GUIDE.md when locating non-obvious functions, data paths, or ownership points
