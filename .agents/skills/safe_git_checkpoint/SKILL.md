# Skill: safe-git-checkpoint

Use this skill before branch creation, commit, push, or other Git write actions.

Checklist:
- inspect `git status`
- confirm current branch
- inspect changed files
- ensure no unrelated files are included
- do not run destructive commands without explicit approval
- do not push or merge without explicit approval
check docs/FIELD_GUIDE.md when locating non-obvious functions, data paths, or ownership points
